About

Google Cloud offers App Engine, a fully managed serverless platform to build and host scalable applications. This project has been created to make use of this service and is just an example. The aim is to just create a demo site and deploy it successfully to Google App Engine via Terraform.

Ideally, each environment will have a different static website deployed/updated. However at this moment in time the same static site will be deployed to each environment. Additionally, any new code committed to this project 'main' branch will be automatically deployed.

Please note that this site and files is just for demonstration purposes, all images and fonts used belong to their respective owners.
